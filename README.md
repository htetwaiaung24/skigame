# ASCIIスキー

## ゲームの概要

Windowsのターミナルで遊べるスキーゲームです。プレイヤーは左右どちらかに滑り続けます。木や崖をよけながら、できるだけ長く滑って最高得点を目指します。途中でシールドを拾うと、木に1回ぶつかっても滑り続けることができます。

## 動作環境

- Windows 10 / 11
- Python 3
- キーボード入力ができるターミナル（VS Codeの統合ターミナルなど）

Pythonの標準ライブラリを使用しています。追加のライブラリをインストールする必要はありません。

## インストール方法

1. WindowsにPython 3をインストールします。
2. GitHubの「Code」から「Download ZIP」を選び、ダウンロードしたZIPファイルを展開します。`git clone` で取得することもできます。
3. `ski_game.py` が入っているフォルダーをVS Codeで開きます。

## 起動方法

VS Codeの「ターミナル」から「新しいターミナル」を開き、次のコマンドを実行します。

```powershell
python ski_game.py
```

タイトルが表示されたら、ターミナル内をクリックして `Space` キーを押すと滑走が始まります。

## 操作方法

| キー | 操作 |
|---|---|
| `Space` | スタート・一時停止・再開 |
| `←` または `A` | 左に滑る |
| `→` または `D` | 右に滑る |
| `R` | 距離と得点をリセットしてスタート画面に戻る |
| `Q` または `Esc` | ゲームを終了する |

### 画面の見方とルール

| 記号 | 意味 |
|---|---|
| `O` | 通常のプレイヤー |
| `S` | シールドアイテム。重なると取得できる |
| `Q` | シールドを装備したプレイヤー |
| `A` | 木。シールドがある場合は1回だけ衝突に耐えられる |
| `*` | 崖。シールドを装備していても落ちるとゲームオーバー |
| `X` | ゲームオーバーになった位置 |

距離が1増えるごとに10点入ります。滑る距離が長くなると、少しずつ速度が上がります。コースの左右の端を越えるとゲームオーバーです。もう一度遊ぶときは `R` を押してから `Space` でスタートします。

## 追加・改良した機能

### 1. シールドアイテム

コースに出現する `S` を拾うと、プレイヤーの表示が `O` から `Q` に変わります。その状態で木にぶつかると、シールドを消費して滑走を続けられます。シールドを使ったあとは `O` に戻るので、次に木にぶつかるとゲームオーバーです。

### 2. ゲームオーバーの原因表示

木にぶつかったとき、崖に落ちたとき、コースの外に出たときで、表示するメッセージを変えました。プレイヤーは何が原因で失敗したかを画面で確認できます。

### 3. 最高得点の記録

プレイ中の得点が最高得点を超えると、記録を更新します。`R` でリスタートすると今回の得点は0に戻りますが、最高得点は次のプレイに引き継がれます。

### 4. 一時停止中の案内

ゲーム開始前には「[Space]でスタート」、一時停止中には「一時停止中 [Space]で再開」と表示します。ゲームの状態と次に押すキーが分かるようにしました。

## 既知の問題・制限事項

- キー入力にWindows用の `msvcrt` を使用するため、Windows環境が必要です。
- 画面全体を表示するには、横60文字・縦21行以上のターミナルが必要です。「ターミナルを広げてください」と表示されたら、ターミナルの表示領域を広げてください。
- 最高得点をファイルに保存する機能は未実装です。ゲームを終了すると記録はリセットされます。
